# Midnight Fridge Roast

One line, 156 characters, roasting a smart fridge that refuses to open after midnight.

> I came down at 1 AM for one slice of cheese and my fridge made me say the password, which is 'I promise this is the last time,' which we both know is a lie.

Run `python3 main.py` — it writes the line to `/output/entry.txt` and prints it.
